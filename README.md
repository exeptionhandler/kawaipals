# ✨ KawaiPals – Minecraft Fabric Mod (26.2)

<p align="center">
  <b>Compañeros espirituales kawaii coleccionables inspirados en los Slime Sprites de Fortnite para Minecraft 26.2.</b><br>
  <i>¡Captúralos con minijuegos en cofres de mazmorras, desbloquea sus poderes y surca los cielos con Pegasito!</i>
</p>

---

## 🌟 Características Principales

- 💖 **12 Espíritus Coleccionables**: Divididos en 4 rarezas (Común, Raro, Épico, Legendario) con poderes pasivos únicos.
- 🎨 **Diseño Kawaii Estilo Fortnite**: Cuerpos gelatinosos tipo cápsula translúcida, núcleo interior brillante, ojos tiernos y animaciones *squash & stretch* fluidas con GeckoLib 5.x.
- 📦 **Encuentros en Estructuras**: Al abrir cofres en templos, mazmorras o bastiones, ¡el espíritu sale con una ráfaga de partículas y activa un minijuego de captura!
- 🎮 **3 Minijuegos de Captura**:
  - 🎯 **Timing Ring**: Presiona en el momento exacto cuando el anillo exterior coincida con el círculo objetivo.
  - ⚡ **Sequence QTE**: Presiona la secuencia de flechas en el orden correcto antes de que acabe el tiempo.
  - 🎣 **Affinity Bar**: Mantén presionado para mantener el nivel en la zona verde hasta llenar la afinidad.
- 📖 **Compendio de Espíritus (Pokédex)**: Un libro interactivo con cuadrícula de espíritus descubiertos y faltantes, filtros de rareza y estadísticas de progreso.
- 🔮 **Pal Orb**: Guarda o invoca a tus compañeros cuando los necesites con Shift + Clic derecho.
- 🦄 **Pegasito (Montura Voladora)**: ¡Súbete a tu Pegasito legendario y vuela por el mundo!

## 🛠️ Requisitos e Instalación

- **Minecraft**: 26.2 (Chaos Cubed)
- **Mod Loader**: Fabric Loader 0.19.3 o superior
- **Dependencias**:
  - [Fabric API](https://modrinth.com/mod/fabric-api) (0.155.0+26.2)
  - [GeckoLib 5](https://modrinth.com/mod/geckolib) (5.5.5 para Fabric 26.2)
- **Java**: Java 25

Coloca el archivo `kawaipals-1.0.0.jar` junto con las dependencias en la carpeta `.minecraft/mods/`.

---

## 🔨 Compilación desde el Código Fuente

```bash
# Clonar el repositorio
git clone https://github.com/exeptionhandler/kawaipals.git
cd kawaipals

# Compilar con Gradle (requiere JDK 25)
./gradlew build
```

El archivo compilado se generará en `build/libs/kawaipals-1.0.0.jar`.
